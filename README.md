## About This Repository

This repository contains coursework, labs, exercises, exam preparation tasks, and mini-projects completed during my software engineering journey.

The goal is to:
- Build strong C# fundamentals
- Practice clean and maintainable code
- Develop problem-solving skills through algorithmic tasks
- Apply OOP principles and testing practices
- Work with databases through ADO.NET and Entity Framework

## Learning Path

### 1) C# Basics
Core programming fundamentals:
- First steps in coding
- Conditional statements
- Loops (`for`, `while`)
- Basic problem-solving exercises

### 2) C# Fundamentals
Intermediate foundations:
- Arrays, lists, and associative arrays
- Methods and reusable logic
- Objects and classes
- Text processing and regular expressions
- Exam preparation and practical problem sets

### 3) C# Advanced
Advanced language and data structure usage:
- Stacks and queues
- Sets and dictionaries
- Multidimensional arrays
- Functional programming (LINQ and delegates)
- Generics
- Streams, files, and directories
- Defining classes

### 4) C# OOP
Object-oriented software design:
- Encapsulation
- Inheritance
- Polymorphism
- Interfaces and abstraction
- SOLID principles
- Reflection and attributes
- Unit testing, mocking, and TDD labs
- Exception handling

### 5) Entity Framework
Data access and persistence:
- ADO.NET
- Entity Framework introduction
- Entity relations
- Advanced querying
- XML processing
- Practical data-driven projects

## How To Use

1. Clone the repository:

```bash

```

2. Open the solution or project folder in Visual Studio.
3. Build and run tasks from the corresponding module directory.
